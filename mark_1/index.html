Axiom of Completeness

The axiom of completeness guarantees us that the number line is complete. This is meant in the sense that the number line doesn't have any holes or gaps in it. Every point on the number line would correspond to a real number.

\(A \subseteq \mathbb{R}\) is bounded above if and only if there exists \(b \in \mathbb{R}\) such that

\[ a \leq b \qquad \text{for every } a \in A. \]

In this case, \(b\) is called an upper bound of \(A\).

\(A \subseteq \mathbb{R}\) is bounded below if and only if there exists \(l \in \mathbb{R}\) such that

\[ l \leq a \qquad \text{for every } a \in A. \]

In this case, \(l\) is called a lower bound of \(A\).

Every nonempty subset of the real numbers that is bounded above has a least upper bound in \(\mathbb{R}\).

\[ S \subseteq \mathbb{R},\quad S \neq \varnothing,\quad S \text{ bounded above} \quad \Longrightarrow \quad \exists s \in \mathbb{R} \]

\(S\) is bounded above, so there exists an upper bound \(u\) such that

\[ x \leq u \qquad \text{for every } x \in S. \]

A least upper bound exists, so \(s\) satisfies

\[ s \geq x \quad \text{for every } x \in S, \qquad c \geq x\ \forall x \in S \Longrightarrow s \leq c. \]

We prove that if \(A \subseteq \mathbb{R}\) is bounded above, then any upper bound of \(A\) is greater than or equal to every element of \(A\).

Let \(a \in A\). Since \(u\) is an upper bound of \(A\), by definition we have

\[ a \leq u. \]

The inequality \(a \leq u\) holds for every \(a \in A\). Therefore, \(u\) lies to the right of every element of \(A\) on the number line.

Hence

\[ a \leq u \qquad \text{for every } a \in A, \]

which proves that \(u\) is an upper bound of \(A\).

The completeness axiom ensures that bounded sets of real numbers have least upper bounds. Further consequences, examples, and proofs can be developed here.
